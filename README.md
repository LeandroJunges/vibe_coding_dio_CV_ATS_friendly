# ATS CV Optimizer 🚀

O **ATS CV Optimizer** é uma aplicação web que utiliza inteligência artificial para analisar currículos em relação a vagas de emprego específicas.

A plataforma compara o currículo do candidato com os requisitos da vaga, identifica competências e palavras-chave já presentes, aponta oportunidades de melhoria e gera uma versão otimizada do currículo, mantendo apenas informações reais fornecidas pelo usuário.

## ✨ Principais funcionalidades

* 📄 Upload de currículo em PDF ou DOCX
* 🔗 Análise a partir da URL e/ou descrição da vaga
* 🤖 Análise inteligente do currículo
* 🎯 Cálculo de aderência entre currículo e vaga
* 📊 ATS Score
* 🔎 Identificação de palavras-chave relevantes
* ✅ Identificação de competências já presentes no currículo
* ⚠️ Identificação de pontos que podem ser melhor evidenciados
* 💡 Recomendações de melhoria
* ✍️ Otimização das experiências profissionais
* 👀 Comparação entre currículo original e otimizado
* 📝 Editor de currículo
* 📑 Preview do currículo
* 📥 Exportação do currículo otimizado
* 🔐 Sem necessidade de cadastro ou login

## 🎯 Objetivo

O objetivo do projeto é ajudar candidatos a entenderem **o quanto seus currículos estão alinhados a uma vaga específica** e melhorar a apresentação de suas experiências profissionais para aumentar a compatibilidade com sistemas de recrutamento baseados em ATS.

A plataforma não deve inventar experiências, competências, certificações ou informações profissionais. As otimizações são baseadas exclusivamente nas informações fornecidas pelo usuário.

## 🧠 Como funciona

```text
Vaga + Currículo
       ↓
   Análise da IA
       ↓
 Comparação de requisitos
       ↓
  ATS Score + Aderência
       ↓
 Recomendações de melhoria
       ↓
 Otimização do currículo
       ↓
   Preview do novo CV
       ↓
      Exportação
```

## 🚀 Visão do projeto

A proposta é unir **Inteligência Artificial, análise de vagas e otimização de currículos** em uma experiência simples, moderna e intuitiva.

O projeto possui uma identidade visual futurista e tecnológica, refletindo a proposta de utilizar IA para transformar a preparação de currículos para processos seletivos.
